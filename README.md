# 한반도 지진 데이터저널리즘

2005~2026년 한반도 지진 데이터를 수집·정리하고, 깊이·진도·발생 위치를 지도와 함께 탐색할 수 있도록 만든 데이터저널리즘 실습 프로젝트입니다.

## 구성

- HTML 인터랙티브 지진지도
- KMA·웨더아이 기반 CSV 데이터
- 실무 강의안 및 강의 슬라이드

## 교육 주제

- 공공·기상 데이터 수집
- CSV 데이터 정제와 필드 설계
- 지진 위치·깊이·진도 시각화
- 데이터 기반 기사와 설명자료 작성

## 출처와 검증

데이터를 재사용하거나 최신 자료로 갱신할 때는 각 CSV의 원천기관, 수집일, 결측치와 중복 여부를 확인하세요.
