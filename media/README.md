# 데이터저널리즘 미디어 자산

이 폴더에는 `KMA_지진_깊이진도_2005_2026.csv`를 바탕으로 제작한 세로형 데이터저널리즘 영상과 시각화 이미지를 수록합니다. 영상은 9:16 비율(720×1280), 44초 길이의 H.264 MP4이며, 지도 인트로·아웃트로와 함께 지진 기록 개요, 연도별 추이, 규모 분포, 권역 분포, 고규모 기록을 순서대로 보여 줍니다.

그래프의 주요 값은 2005년부터 2026년 6월 16일까지의 1,769건 기록을 집계한 결과입니다. 위치 권역은 원본 위치 텍스트의 첫 행정권역을 기준으로 단순 집계했으며, 정밀 공간 분석을 대체하지 않습니다.

| 파일 | 설명 |
|---|---|
| `korean_earthquake_data_journalism_vertical_extended.mp4` | 세로형 확장 영상 |
| `01_overview.png` | 기간·건수·규모·깊이 개요 카드 |
| `02_yearly_trend.png` | 연도별 기록 건수 추이 |
| `03_magnitude_distribution.png` | 규모 구간별 분포 |
| `04_regional_distribution.png` | 위치 텍스트 기반 권역 분포 |
| `05_key_events.png` | 규모 상위 5개 기록 표 |
| `vertical_map_keyframe.png` | 영상용 한반도 지도 키비주얼 |
